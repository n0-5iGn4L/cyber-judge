# 使用选定的 DS 报告模板

## 默认视觉

使用 assets/report-template 中的模板：墨色书脊、暖纸正文、宋体判词、黑体记录、朱红证据标记和页边支持度批注。这是用户选定的 DS 版本，默认沿用。不要每次运行重新设计、替换为仪表盘，或因为争论点多就缩减研究。

## 内容与生成

调研覆盖检查通过后，依据 [report-data.md](report-data.md) 生成报告 JSON，再调用 scripts/build.mjs。纯文本内容与模板分离；来源和正文都在构建时写入 HTML，成品无需在线字体、框架或相邻 JSON。

起因经过、各方角色、每项争论点的主张／支持度／理由与裁定默认可读。长方法说明放在附录。短评可为空；不强行为严肃事件写笑话。判词卡保留完整局部裁定，不用程序机械截掉第二句可能重要的限定。

争论点数量由调研决定，导航与编号自动增长。实际长文应逐项渲染，无上限截取。公共议题的方案比较写成对应争论点，页面类型自动显示为公共议题。

## 检查

- 构建前校验字段、唯一编号、来源引用、网页 URL 和可安全写出的文件名。
- 构建后核对报告中所有争论点与数据一致，引用能跳到来源、来源能回到正文；主要结论可找到实际依据。
- 真实浏览器查看桌面和 375px 手机布局，特别检查长标题、多争论点目录、多方主张和长 URL。
- 目录、证据回链、键盘焦点、关闭目录和打印可用；无 JavaScript 时正文与锚点仍可读，打印不丢折叠内容。
- 信息不用颜色单独表达；尊重减少动态效果偏好。模板不引入网络请求、自动音频或额外第三方素材。

渲染器负责结构，不负责事实判断或调研充分性。示例只是模板用法，不能作为调查争论点数量或证据标准的上限。
